# Maintainers

Maintainers review and merge changes, triage issues, cut releases and enforce the
[Code of Conduct](CODE_OF_CONDUCT.md). See [GOVERNANCE.md](GOVERNANCE.md) for how the project is
run and how to become a maintainer.

The whole group is the GitHub team **`@andai/iptether-maintainers`**. Mentioning the team in an
issue or pull request reaches all of them.
